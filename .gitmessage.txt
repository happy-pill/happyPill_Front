# <타입>: <변경 내용 요약>
# 예시: feat: 회원가입 기능 구현

# 타입 목록:
# feat     : 새로운 기능을 추가
# fix      : 버그 수정
# refactor : 코드 리팩토링
# design   : CSS 등 사용자 UI 디자인 변경
# style    : 코드 포맷 변경, 세미 콜론 누락 등 (코드 동작에 영향 없음)
# comment  : 필요한 주석 추가 및 변경
# docs     : 문서 수정
# chore    : 빌드 업무, 패키지 매니저 설정 등 (Production 코드 변경 없음)
# rename   : 파일 또는 폴더 이름만 변경
# remove   : 파일을 삭제하는 작업만 수행한 경우
